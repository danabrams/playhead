# scripts/sim-trim-jobs.txt — launchd jobs the merge gate boots the simulator WITHOUT.
#
# playhead-blsh, option B. Read scripts/sim-trim.sh for the mechanism and for the
# measurement that made `simctl boot --disabledJob` unusable here.
#
# FORMAT:  <launchd label>  # <family> — why an audio-podcast unit-test gate does not need it
#
# ADMISSION RULE, and it is the whole safety argument: a label goes in TIER A only
# when the framework it backs is imported NOWHERE in Playhead/ or PlayheadTests/.
# Measured on this tree with `grep -rl '^import <F>'`:
#
#     HealthKit 0 · CoreLocation 0 · MapKit 0 · Photos 0 · EventKit 0 · Contacts 0
#     WidgetKit 0 · ActivityKit 0 · CoreSpotlight 0 · CallKit 0 · Intents 0 · WebKit 0 · Vision 0
#
# and against the frameworks that ARE imported — AVFoundation, MediaPlayer, Speech,
# UserNotifications, BackgroundTasks, FoundationModels, StoreKit, CloudKit, CoreML,
# SwiftData, SwiftUI/UIKit — nothing here backs one. The daemons that do are in the
# KEEP list in sim-trim.sh, which is the enforced half of this claim.
#
# TIER B (siri/intelligence/speech) is NOT in this file. It is DAN'S COVERAGE
# DECISION, not an implementer's: Speech and FoundationModels are both imported.
# It lives in sim-trim-jobs-tier-b.txt and only `--include-tier-b` reads it.
